# Creative Agency Portfolio Platform

A modern, high-performance portfolio website built for creative agencies, studios, or freelancer teams. This platform features a sleek, responsive design with dynamic content management and a premium user experience.

## ✨ Key Features

- **🚀 Performance-First**: Built with Next.js 16 and React 19 for lightning-fast loading speeds and optimal SEO.
- **🖼️ Interactive Portfolio**: A dynamic gallery with category-based filtering and lightbox support.
- **👥 Team Profiles**: Dedicated dynamic pages for team members with skillsets, experience, and personal portfolios.
- **📱 Responsive Design**: Fully optimized for mobile, tablet, and desktop using Tailwind CSS.
- **📩 Contact System**: Integrated contact form with validation and status feedback.
- **💎 Premium UI**: Featuring glassmorphism, smooth animations, and curated typography (Montserrat & Poppins).

## 🛠️ Technology Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Data Architecture**: JSON-driven content management for easy updates without a complex database.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd webportofoliotim
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Deployment

To deploy this application to production:

1. Build the project:
   ```bash
   npm run build
   ```

2. Start the production server:
   ```bash
   npm run start
   ```

Alternatively, you can easily deploy to **Vercel** or **Netlify** by connecting your repository.

## 📂 Project Structure

- `app/`: Next.js App Router pages and layouts.
- `components/`: Reusable UI components.
- `data/`: JSON files containing portfolio and team member data.
- `public/`: Static assets like logos and images.
